# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability. A public issue tells everyone about the problem before a fix exists.

Report it privately with GitHub private vulnerability reporting:

1. Go to https://github.com/briebug/mcp-gsc/security/advisories/new.
2. Describe the problem, the affected commit or version, and the steps to reproduce it.
3. Do not include real credentials, tokens or Search Console data in the report.

We reply to a report within 5 business days.

## Scope

This policy covers this fork, `briebug/mcp-gsc`. For a problem that is also in the upstream project, `AminForou/mcp-gsc`, report it to us first. We coordinate with upstream.

## Supported versions

Only the latest commit on `main` gets security fixes. Install from a reviewed commit of this repository, never from the PyPI package `mcp-search-console`.
